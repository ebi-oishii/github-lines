GitHub Lines

GitHub のファイル一覧に、ディレクトリ内での行数の割合バーとツリーマップを表示します。

アクセストークン

未設定でも public リポジトリでは動作しますが、GitHub API のレート制限が 60 回/時 になります。トークンを登録すると 5,000 回/時 になり、private リポジトリでも使えます。

複数のアカウントを使い分けている場合は、トークンを複数登録して オーナー（ユーザー名 / Organization 名）ごとに割り当てられます。 あるアカウントのトークンで別アカウントの private リポジトリは読めないためです。

Fine-grained token を作成 — 必要な権限は Repository permissions → Contents: Read-only のみです。 トークンはこの端末の chrome.storage.local にのみ保存され、 api.github.com 以外には送信しません。

閾値

1 ファイルの行数がこの値を超えたら色を変えて警告します。

表示

行数のカウント

取得した行数は blob SHA をキーにキャッシュされます。git の blob SHA は内容のハッシュなので、 ブランチやコミットが変わっても内容が同じファイルは再取得されません。

除外

バイナリ（画像・フォント・アーカイブ等）は拡張子で判定して常に除外されます。
